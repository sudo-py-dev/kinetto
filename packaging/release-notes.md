## Install

| System | Download |
|---|---|
| Ubuntu, Debian | `kinetto_<version>_amd64.deb`, then `sudo apt install ./kinetto_<version>_amd64.deb` |
| Windows 10 and 11 | `kinetto-<version>-windows-x86_64-setup.exe` |
| macOS 11 or newer (Apple Silicon and Intel) | `kinetto-<version>-macos-universal.dmg`, then drag Kinetto into Applications |

Each package includes the editor and `kinetto-cli`. `SHA256SUMS.txt` lists every file's checksum.

These builds aren't signed by a publisher yet:

- **Windows** may show "Windows protected your PC". Choose **More info**, then **Run anyway**.
- **macOS** says the app can't be checked the first time. Open **System Settings → Privacy & Security** and choose **Open Anyway**.
